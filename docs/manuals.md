# Manuals — Link List

Curated links for the "manuals I need." Every link is for something actually
used on this system.

## NixOS & Nix
- NixOS Manual (stable): https://nixos.org/manual/nixos/stable/
- NixOS options search (`nixos options` UI): https://search.nixos.org/options
- NixOS Wiki (concepts, hardware, guides): https://wiki.nixos.org
- Nixpkgs (packages): https://nixpkgs.wiki
- `nixos-rebuild`, `home-manager` usage: covered in [docs/shortcuts.md](shortcuts.md)

## Window manager — Niri
- Niri (repo + wiki + config reference): https://github.com/wilmor/niri
- NixOS `programs.niri` option: https://nixos.org/manual/nixos/stable/options#opt-programs.niri
- Your live config: `~/.config/niri/config.kdl` (see [docs/niri.md](niri.md))

## Desktop shell — Noctalia
- Noctalia (repo + wiki): https://github.com/noctalia-dev/noctalia
- Noctalia wiki (themes, keybindings, config): https://wiki.noctalia.org
- Your live config: `~/.config/noctalia/config.toml` (see [docs/noctalia.md](noctalia.md))

## Browsers
- **Zen** (default browser, via flake): https://zenbrowser.com
- Firefox (base, still installed under the hood): https://firefox.mozilla.org

- tmux: `man tmux` · https://github.com/tmux/tmux/wiki
- Your tmux setup: [docs/tmux.md](tmux.md)

## Neovim
